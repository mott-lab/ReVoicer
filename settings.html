Settings

Offline Mode
Voice notes are transcribed locally (Local Whisper if its model is already cached, otherwise the bundled Vosk transcript). Notes are saved raw and marked "pending cleanup" — clean them from the sidebar when back online. Q&A, Organize, Review, and citation lookup are unavailable while on.
Text Processing
When off, typed/voice annotations are saved verbatim with a heuristic type label. Q&A and Organize still need a provider.

Review Model

Review Style
A folder of .txt or .md example reviews, used by Generate style guide below (up to 20 files / 20,000 characters are read).
Generating analyzes the example reviews with the Review model and replaces the style guide below. The result is saved immediately.
Describe the voice, tone, and formatting the review should follow — treated as style guidance distinct from the instructions below.
Review Instructions
Describes the structure of the annotation data sent to the model — the notes JSON fields, references, and rubric. Edit only if you change what the model should pay attention to.
Tone, format, and process guidance for the review. The app saves the review file itself — any instruction telling the model to save or write files is ignored.
Tip: For higher-quality reviews, generate a style guide from a folder of your past reviews and write detailed instructions describing how the review should be structured and worded.
Reference Lookup
Used when clicking an in-text citation to fetch its title, authors, and abstract. Lookups happen only on click and are cached per PDF. Without a key, requests use Semantic Scholar's shared pool, which is heavily rate-limited. Request a free key at semanticscholar.org/product/api.
Reference Library
A .bib file searchable from the sidebar's References tab. It is re-read automatically whenever the file changes — point it at a Zotero Better BibTeX auto-export ("Keep updated") to stay in sync with your library.
Highlights
When off, all highlights use a yellow background. When on, each highlight is colored by its primary tag. Click a tag on a note (or the color swatch) to recolor one highlight.
